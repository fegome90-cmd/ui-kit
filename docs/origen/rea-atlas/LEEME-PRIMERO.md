# REA Atlas — paquete completo v4

Incluye la versión más reciente del HTML de REA Atlas (sin cursor de regla ni recuadros azules), los componentes de referencia, tokens, código, scripts, pruebas, capturas de escritorio y móvil, informes de fidelidad, investigación y el workflow de extracción hacia shadcn.

## Accesos principales

- `rea-design-library-reference/site-concept.html`: HTML más reciente; abrir directamente en el navegador.
- `rea-design-library-reference/README.md`: documentación para ejecutar los ejemplos React/Storybook y las pruebas.
- `rea-design-library-reference/CHANGES-V4.md`: últimos cambios (cursor normal y retiro de cuadros azules).
- `rea-design-library-reference/DIFF-1VS1.md`: comparación con la referencia visual.
- `rea-design-library-reference/FIDELITY.md`: límites de fidelidad y QA.
- `investigacion_bibliotecas_diseno_humano_agente_2026-10-16.md`: investigación con ejemplos de código y arquitectura.
- `design-to-registry-workflow/SKILL.md`: skill para extraer y reconstruir componentes.
- `design-to-registry-workflow/WORKFLOW.mmd`: diagrama Mermaid del workflow.

Se preservan versiones HTML y capturas históricas para comparación. Se omiten otros ZIP ya generados porque duplicarían estos archivos.
